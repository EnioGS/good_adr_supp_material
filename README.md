# Supplementary material

Material of a study on what makes a good architecture decision record (ADR), carried out in two phases: interviews, followed by a survey.

| File | Content |
|---|---|
| `interviews/interview-guide.md` | Guide of the semi-structured interviews. |
| `interviews/codebook.csv` | The 76 codes that resulted from the analysis of the interviews, in nine categories. Each code has a definition, notes on when to use it and when not to, and the number of interviews (of 14) in which it appears. |
| `interviews/agreement.md` | Agreement between the two coders in each of the four coding rounds. |
| `survey/questionnaire.md` | The questionnaire: 39 questions with their options. |
| `survey/summary.md` | The answers of the 50 respondents, as counts per option and per point of each scale. |

Interview transcripts and individual survey answers are not shared, to protect the identity of the participants.
